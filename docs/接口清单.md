# 云枢 OA · REST 接口清单

统一前缀 `/api`；统一响应体 `{ code, msg, data, timestamp }`，`code=200` 表示成功。
除 `POST /api/auth/login`、`GET /api/health` 外，其余接口均需请求头
`Authorization: Bearer <token>`。

错误码：`400` 业务异常 / `401` 未登录或登录失效 / `403` 无权限 / `422` 参数校验失败 / `500` 服务异常。

## 认证 AuthController

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/login` | 账号密码登录，返回 token / user / roles / perms / menus |
| GET | `/auth/info` | 按 token 拉取当前用户信息与权限 |
| PUT | `/auth/password` | 修改密码（校验原密码，新密码 ≥6 位） |
| POST | `/auth/logout` | 前端清除 token（JWT 无状态） |

## 健康检查

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 返回状态 / 版本 / JVM 运行时长 / Java 版本，无需鉴权 |

## 请求示例

```bash
# 登录取 token
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"123456"}' | jq -r .data.token)

# 工作台
curl -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/dashboard/overview

# 发起请假审批
curl -X POST http://localhost:8080/api/approvals/instances \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"procKey":"leave","title":"张伟 - 年假申请 11/13-11/14（2 天）",
       "form":{"leaveType":"年假","startDate":"2026-11-13","endDate":"2026-11-14","days":2,"reason":"家庭事务"}}'

# 审批通过
curl -X POST http://localhost:8080/api/approvals/12/approve \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"comment":"同意报销"}'

# 会议室冲突检测（会返回 400）
curl -X POST http://localhost:8080/api/calendar/events \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"测试","roomId":2,"startTime":"2026-11-09 10:30","endTime":"2026-11-09 11:30","attendees":"张三"}'
```
