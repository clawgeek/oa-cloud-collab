## 制作方式（为什么"没有抖动"）

- **界面素材全部是真实截图**：Playwright 驱动真实浏览器打开本机运行的 `localhost:5173`，
  真实登录、真实提交表单、真实审批通过，在每一步截取 1440×810 @2x 的系统画面。
- **部署终端内容全部是真实执行输出**：摘自本机 `mvn package`、`java -jar`、`npm run build`、
  `curl /api/health` 的 stdout，生产配置部分直接 `grep` 仓库内配置文件。
- **逐帧确定性渲染**：所有鼠标轨迹、高亮框、镜头切换、终端打字都由
  `window.renderAt(t)` 按虚拟时钟计算，不使用 CSS 动画、不依赖宿主时钟、无随机量，
  因此帧数 = 页时长 × 25 严格成立，音画天然对齐，且没有手持录屏的抖动。
- **一条时间轴**：配音时长 → 字幕时间码 → 页面时长 → 录屏帧数全部由同一公式推导，
  不存在手工对齐误差。

```bash
cd OA云协同_项目讲解
pip install -r requirements.txt
python tools/doctor.py          # ffmpeg(libass) / 浏览器 / TTS 自检
python tools/make.py            # 全流程：配音 → 字幕 → 录屏 → 合成
```
