# 云枢 OA · 业务说明与演示脚本

## 一、典型业务场景（一条审批流走完）

> 场景：市场部陈曦提交「双十一投放追加预算报销 ¥8,600」，需要部门负责人 → 财务复核 → 总经理终审。

1. **发起**：陈曦登录 → 审批中心 / 我的申请 → 发起审批 → 选「费用报销流」→ 填金额、类别、事由 → 提交
2. **建单**：后端读 `wf_process_def`（expense），解析 nodes_json，创建 `wf_instance`（RUNNING，当前节点 leader），
   并给「部门负责人」赵启帆创建一条 PENDING 任务
3. **一级审批**：赵启帆在「待我审批」看到该单 → 通过 → 后端把任务置 DONE 并写入意见，
   推进到 finance 节点，给何静怡创建新任务
4. **二级审批**：何静怡核验票据 → 通过 → 推进到 gm 节点，给周明远创建新任务
5. **终审**：周明远（admin）在「待我审批」看到 → 通过 → 已是最后节点，实例置 `APPROVED` 并写 `finish_time`
6. **留痕**：任意时刻打开审批详情，能看到表单快照、流程节点与全部审批意见时间线

**驳回分支**：任一节点选择驳回 → 实例 `REJECTED`，剩余待办任务 `CANCELED`，流程终止。
**撤回分支**：申请人在单据 RUNNING 时可撤回 → 实例 `WITHDRAWN`。

> 演示库已预置 4 条处于「总经理终审」的报销单，`admin` 登录后可直接演示第 5 步。

## 二、其他业务规则

| 场景 | 规则 |
| --- | --- |
| 考勤 | 09:00 后上班打卡判 `LATE`；18:00 前下班打卡判 `EARLY`；工时 = 上下班时长 - 1h 午休 |
| 公告 | 打开详情即写 `oa_notice_read` 回执，`view_count + 1`；顶栏铃铛显示未读数 |
| 云文档 | 上传真实写入 `OA_UPLOAD_DIR`，`doc_file` 记录版本与大小；下载时计数 +1 |
| 任务看板 | 状态流转到 DONE 自动把 `progress` 置 100，REVIEW 置 90，DOING 置 50 |
| 会议室 | 同一会议室 `start_time < 新结束 && end_time > 新开始` 即冲突，返回业务异常 |
| 员工删除 | 内置 admin（id=1）禁止删除；部门存在子部门时禁止删除 |
| 新增员工 | 初始密码 `123456`，经 PBKDF2 散列后入库，数据库中不存明文 |

## 三、角色与权限矩阵

| 角色 | 数据范围 | 典型权限 |
| --- | --- | --- |
| 系统管理员 ADMIN | ALL | 全部菜单 + `*:*` 通配权限码 |
| 人事专员 HR | DEPT | 组织、考勤、公告、审批、人事备案 |
| 部门经理 MANAGER | DEPT | 审批本部门单据、任务管理、文档管理 |
| 普通员工 EMPLOYEE | SELF | 工作台、打卡、发起申请、查看公告与文档 |
